FOLDER /dane — baza zdjęć do jackpota
=====================================

Wrzuć tutaj swoje grafiki (jpg / png / gif / webp / svg).

WAŻNE:
Przeglądarka w Margonem NIE może czytać dysku C:\ sama z siebie.
Dlatego w dodatku masz 3 sposoby na wgranie zdjęć:

1) W grze: przycisk "Wgraj zdjęcia z /dane"
   — wybierz wszystkie pliki z tego folderu.

2) Wklej linki URL w konfiguracji skryptu (CONFIG.images).

3) Ustaw CONFIG.daneBaseUrl na adres, pod którym hostujesz ten folder
   (np. GitHub raw / własny hosting) i dopisz nazwy plików w CONFIG.daneFiles.

Pliki 01–08 *.svg to przykładowe "karty pecha".
Możesz je usunąć i wrzucić własne memy.
